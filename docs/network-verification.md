# 弱网与断线恢复验收

2026-11-18，Edge 157.0.4341.60在1440×1000桌面和390×844手机视口通过学习流程和断线恢复验证。每个视口覆盖10项检查，结果见network-result.json，截图为network-desktop.png及network-mobile.png。

## 网络与运行范围

Chromium CDP配置延迟300ms、下载200KiB/s、上传64KiB/s，并在指定时点切换offline。测试使用本机Next.js生产构建网页、隔离FastAPI及SQLite测试库。API请求经过真实浏览器网络。独立API请求上下文读取服务端状态作为断言依据，该观测通道未限速。

服务端聊天使用Demo适配器，断线用例在片段之间增加0.5秒延迟，以便在流式回复进行时切断浏览器网络。真实模型调用为0。浏览器手机视口为模拟设备，iOS Safari和Android真机继续待验证。

## 验收结果

- 登录并创建课程后，断网上传PDF显示错误，服务端文件列表为空。恢复网络后重新选择同一文件成功，随后PPTX、DOCX也解析完成。
- 知识点可编辑确认，生成Demo剧情后进入题目。
- 提交答案前断网，页面显示错误，服务端节点、版本和分数保持一致。
- 恢复网络后，Playwright先将答案真实提交到服务端，再中断返回给网页的响应。服务端存档由version=2推进到version=3、节点为review，错题数量为1。
- 刷新页面并从课程重新进入剧情，恢复到已提交的结局，版本保持3。
- 流式聊天收到片段后切断网络，页面显示中断错误。恢复网络并刷新会话，服务端首条请求只产生一条用户消息和一条回复。
- 本轮两种视口的服务端首条回复均已完成保存。客户端断线时，服务端可能继续完成回复，恢复流程读取其最终状态。脚本允许complete或failed终态，并检查不会遗留processing状态。
- 用户显式发送下一条问题后，新回复为complete且包含课程知识，总共4条消息。流程检查新增消息的服务端内容与状态。
- 两个视口均无横向溢出，page_errors为空。临时API和Next服务在脚本结束时关闭。

本轮桌面流程约32.5秒、手机流程约33.6秒，时间包含自动化操作与等待，用于复跑观察。当前证据覆盖上述固定CDP参数及故障注入，公网运营环境、真实模型流、真实移动设备和目标部署负载保持待验收。

## 复跑

项目虚拟环境需要已有测试依赖和本机Edge，前端需要已完成生产构建。脚本自行启动临时端口，创建合成账号，结果保存到docs，数据库与启动日志保存在已忽略的test-results/network-*目录。

```powershell
Push-Location frontend
npm.cmd run build
Pop-Location
.\.venv\Scripts\python.exe scripts\network_probe.py
```

首次两次在受限运行环境中无法访问临时回环端口，随后在具备本机网络权限的环境完成。测试开发期间补充了页面就绪等待，并校正了聊天断线后服务端可以正常完成的断言。network-result.json保留最终通过结果，前序失败目录保留用于排查。
