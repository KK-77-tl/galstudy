# GalStudy 评委演示脚本

版本为2026-11-17本地Demo，目标时长约2分40秒。讲述对象为首次接触项目的评委。

## 演示前准备

启动本地API和生产构建网页，使用演示专用账号。备好 tests/samples/original.pdf，PPTX与DOCX可作为补充。预先保留一个已确认知识点且已生成剧情的项目，以及一个完成Mock生成的角色，以便跳过等待。录制时隐藏邮箱、开发者工具Cookie、密钥配置和其他人的教材。

当前知识点采用原文摘录，剧情采用模板，聊天默认Demo。角色工坊采用模拟支付及预设演示立绘。开场与工坊讲述需保留这些状态。

## 0分00秒至0分20秒

操作首页，经过现有序章与章节选择，进入学习空间。

讲述「GalStudy面向用自己的课件复习的学生。上传材料后，先校对知识点，再进入可以选择分支和答题的视觉小说。当前展示的是本地Demo，教材摘录、剧情模板和陪学回复均有模式标记。」

## 0分20秒至0分55秒

创建学习项目，上传原创PDF，等待解析。展开来源，编辑一个知识点并确认。若现场解析等待过长，切到预先准备的项目，同时说明正在切换。

讲述「系统保留文件与页码，PPTX对应幻灯片，Word对应内容块。知识点可以修改、补充和删除，确认后才进入剧情与陪学检索。」

## 0分55秒至1分35秒

生成或打开准备好的双章节剧情。选择一个路径，在题目故意答错，查看解析与教材引用，打开错题本并复习。返回剧情，刷新页面验证存档。

讲述「节点、分支、正确答案与分数由服务端状态机管理。答错会保存到错题本，剧情版本和当前进度一起保存。这里的题目是基于确认知识点生成的摘录识别题。」

## 1分35秒至2分00秒

打开悬浮陪学，问「检索练习是什么」，查看来源。切换角色，再问课程资料没有覆盖的问题。拖动并收起组件。

讲述「陪学按账号、课程与角色隔离，会引用本课程已确认的内容。资料不足时会提示缺少依据。最近对话和摘录记忆可以保留，用户能清空会话。」

## 2分00秒至2分30秒

打开角色工坊，展示权利确认、参考图保留期、订单和模拟付款按钮。用预先交付的角色说明资产清单中的占位提示，再选择该角色进入剧情及陪学。

讲述「这部分为Mock支付和Mock生图演示。服务端决定价格，付款状态通过模拟签名通知核验，一次性权益控制生成，失败恢复权益。当前输出使用预设演示图，各表情与姿态的占位状态已列出。真实GPU与支付宝收款待实际接入验证。」

## 2分30秒至2分40秒

展示手机尺寸或手机截图，以及文档中的测试结果。

讲述「目前已验证本地学习主流程、桌面与手机操作。下一步是实际模型质量评估、角色一致性和真实支付交付验收。学习效果与商业收入还需要真实用户研究和交易验证。」

## 90秒压缩版

用准备好的项目直接依次展示知识点出处、一道错误分支、错题与存档、一次带引用的陪学、Mock角色选择。开场说明Demo模式，结尾说明真实服务待验收。保持每个画面约15秒，省去现场上传与等待。
