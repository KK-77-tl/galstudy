2026-11-23更新。本地默认Demo。OpenAI兼容适配器已通过协议与业务测试，并新增Cloudflare真实调用实验：原创知识提炼与逐字引用通过，剧情与流式聊天的完整真实验收尚未通过。已部署私有模型网关，失败、网络限制及后续配置见cloud-live-verification.md。

## 配置

在服务端.env设置LLM_MODE=cloud，以及LLM_BASE_URL、LLM_API_KEY、LLM_MODEL。LLM_BASE_URL采用服务商所选区域的HTTPS基础地址，适配器追加/chat/completions，拒绝URL内凭据、查询串和片段。知识提炼与剧情使用同一配置，LLM_CHAT_MODE独立控制陪学。必要配置缺失时使用Demo，重启API后生效。

所选模型需要支持response_format的json_object模式。请求中的系统提示包含JSON及目标schema，应用再执行Pydantic与业务校验。JSON Object模式保证输出形态，应用负责字段、来源和图结构约束，模型支持范围需按服务商当期文档确认。[阿里云结构化输出文档](https://www.alibabacloud.com/help/en/model-studio/qwen-structured-output)

## 知识提炼

上传记录保存实际draft_mode。后台先运行受45秒限制的文档解析子进程，长来源切段，短来源合批，每批最多12000字符、12个来源片段，避免逐段落消耗一次请求。输出包括source_id、definition/concept/pitfall/exercise类型、中文可编辑text与逐字quote，每批1至24条。source_id仅能指向当前批次，引用必须为该片段的非空连续子串，不能跨来源拼接，未知类型、空内容与编造引用均拒绝。

全部批次验证通过后，原文块、知识草稿与ready状态在同一事务发布。失败保持failed状态并显示可读原因，保留原始文件供用户下载、删除和重试，未完成草稿不发布。重试从整份文件开始，之前失败批次的调用预留量保留。每份文件仍最多尝试3次，大文件可能触及每日额度，界面提供显式Demo摘录重试。

processing_token标识当前执行者。重启恢复会清除旧token并重新排队，发布与错误写入均匹配本轮token。用户删除资料后，后续外部调用前会复核token，最终发布也检查记录，避免旧执行者重新写回已删除资料。已经发出的模型请求可能持续到其超时，供应商侧取消与计费结果需真实服务验证。

迁移006增加文件模式、处理token，以及知识点的mode、kind与quote。旧文件/草稿保留Demo模式，无原文块的历史手工补充标记manual。用户可编辑text并确认，quote保留其原文出处。逐字引用校验验证来源存在性，知识表述和习题正确性仍需用户与教学质量评估核对。

## 剧情生成

POST /api/courses/{id}/story接收expected_revision及可选use_demo。应用仅读取本账号课程的1至12条已确认知识点，按ID固定顺序形成来源快照。模型输出使用point_ids引用这些条目，文件名称、页码/位置与quote由服务器绑定。

云端结果须通过以下检查。

- 章节为1与2，人物限定小栞、遥、凛，场景限定教室与图书馆。
- start至少两个选项，存在至少两个可达结局。
- 图为有限无环结构，所有节点可达，每条路径都能通向结局。
- 每条到达结局的路径必须经过题目，每个确认知识点至少由一道题引用。
- 题目具有不同选项、有效正确答案与解析，来源ID均在本次快照中。
- 节点、文本、选项数量和字段长度有上限，未知字段拒绝。

服务端故事结构沿用Story与现有判分、存档和错题流程。玩家API在答题前隐藏正确答案，答题后返回解析与来源。模型输出无法直接修改分数、订单或账号。

课程story_token在发起云请求前占用，同课程并发生成返回409。网络等待期间释放数据库写锁。返回后重新锁定课程，并检查token、版本、标题和完整确认知识快照。资料变化会返回409并丢弃本次结果。失败与预算拒绝清除占用，已有故事版本和存档继续可用。重启清除中断占用，旧执行者的token校验会拒绝发布。

## 额度与失败

提炼、剧情和聊天共用LLMUsage用户/全局每日请求与预留token桶，按UTC+8划分。调用前按完整请求UTF-8字节数、输出上限与2048协议余量保守预留，预留与提交各自持久化。外部失败、输出校验失败、资料变化而丢弃结果仍保留预留量，避免重试绕过预算。实际费用以供应商账单为准。

知识提炼输出上限4096token，剧情8192token，单次总体超时由LLM_GENERATION_TIMEOUT_SECONDS控制，默认45秒，支持1至120秒。响应体上限1MiB，要求finish_reason为stop。授权、额度、网络、超时、截断、格式及校验失败返回安全错误。上游响应正文与密钥均不向网页透出。实际环境需检查反向代理等待时长能够覆盖该超时配置。

调用失败后保持云模式和错误，用户点击使用Demo模板或Demo摘录重试才切换。当前本地配置保持Demo。已发起真实Workers AI调用并取得用量，尚未核对账单，不能将真实服务完整链路标为通过。

## 契约与验证

knowledge-drafts.schema.json描述模型草稿输出，generated-story.schema.json描述含point_ids的模型剧情，story.schema.json描述绑定来源后的存档图，均位于backend/schemas。

tests/test_learning.py通过模拟传输覆盖分批与预留、伪造引文、空输出、类型错误、结构/来源拒绝、上游授权与额度错误、体积、截断和超时，另经业务API验证上传、确认、生成、隐藏答案、判分、失败后显式Demo、部分批次失败原子性、账号隔离、同课程并发与资料变更拒绝。模拟模型输出使用原创Demo图构造协议样本，这些结果证明适配与业务流程，真实模型叙事质量和知识准确性保持待验收。

scripts/cloud_browser_probe.py使用隔离测试库和临时同源API，载入现有生产构建网页完成桌面/手机浏览器验收。模型调用为模拟HTTP传输，结果及截图分别保存于cloud-browser-result.json和cloud-fixture-*.png。运行前启动本地网页并安装requirements-dev.txt，脚本结束关闭临时API，测试库保留在test-results供排查。
